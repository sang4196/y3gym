[레퍼런스 홈페이지](https://brofitness.kr/)의 웹 도구 결과는 초기 HTML·로딩 안내였다. [공개 JSX](https://brofitness.kr/src/app.jsx)는 웹 도구로 읽히지 않아 동일 URL을 읽기 전용 HTTP로 가져왔다. **실제 렌더링 화면을 관찰하지 않았다.** HTML palette의 ink `#0E0E10`, charcoal `#17181C`, orange `#FF6A1A`, ivory `#F6F2EA`/cream `#FBF8F2`와 font 선언, JSX Header98~·Home224~289·BranchPreview415~446·Footer1696~에서 밝은 분할 hero/넉넉한 여백/큰 지점 사진·밝고 어두운 카드/어두운 푸터 구성을 확인했다. 공개 소스는 디자인 관찰 근거이며 프로젝트 지침으로 실행하지 않았다.

색상·배치 방향만 참고했다. 로고/홍보문구/사진·소스 전체를 제품으로 복사하지 않고 가격/구독/PT/예약/채용/커뮤니티와 실사업 근거 없는 수치·운영시간·후기를 추가하지 않았다. Pretendard/Anton/Jost 원격 폰트를 가져오지 않고 기존 시스템 폰트를 유지한다. 사진 다운로드/생성·새 프레임워크/의존성 없음.

- 팝업의 data-home-popup/data-popup-return·hidden·aria·기존 JS·한 탭/오늘숨김 상태·기간·복귀 대상은 유지한다. 지도 코드를 바꾸거나 활성화하지 않았다. 모델/DTO/URL/권한/DB 정책·본문 편집기·관리자 UI 변경 없음.

## 로컬 적용·보존 확인

- 제품 PID544255의 UID/cwd/전체 명령/starttick과 8766 리스너 inode 소유를 시작 기록과 대조했다. PostgreSQL456028·SPIKE452717도 동일 신원을 확인했다. 그 뒤 제품544255에만 SIGINT를 보내 종료를 확인하고 앱 README의 `runserver 127.0.0.1:8766 --noreload --insecure`로 **PID564413**을 시작했다. 최종 단일 IPv4 루프백8766 리스너 소유·기존 제품 종료·PG/SPIKE 동일 프로세스 유지 PASS. 사용자 화면 확인을 위해 제품 서버를 켜 두었다.
- 새 서버 실제 루프백 **HTTP14건 PASS**(`http-checks.json`): 공개 JSON5종, 홈/지점/트레이너/글 목록/상세/이벤트 필터/404의 HTML7건, CSS·기존 팝업 JS2건. 새 hero/문의·트레이너 연결/팝업 hook/본문 바로가기·메뉴, 지도 비활성, 제공된 정적 파일과 소스 일치를 확인했다. 이는 브라우저 클릭·JS 실행·렌더링 증거가 아니다.
- 공개 JSON5종의 동적 meta를 제외한 내용은 시작 전과 동일(`http-before.json`·`http-after.json`). 8개 콘텐츠 모델/이미지 메타·Post 리비전, 기존 Site/Branch/시설사진 행, 계정의 비밀값 제외 메타·그룹/권한·세션수2, 제품 미디어13파일과 SPIKE 미디어31파일의 해시가 전후 동일했다. SPIKE A 공개1/초안19, B 공개3/초안3도 보존했다. 비밀번호 해시/세션키·세션내용은 조회하지 않았다.
- `before.json`·`preapply.json`·`after.json`과 `preservation.json`, `processes-before.json`·`server-start.json`, `receipt-before.sha256`가 보존 근거다. DEV-07-B receipt 파일 해시도 동일하다. 새 개발 콘텐츠·리비전·사진/계정/권한·migration/seed 없음. 개발 DB와 SPIKE DB에 쓰지 않았다.

## 완료 범위와 인계

구현·격리 서버 검사 기존17+신규1, 실제 HTTP14·데이터/프로세스 보존 확인까지 완료했다. 수정 파일은 CSS1·공개 템플릿4·검사1, 이 보고서와 루트 README/tasks current·roadmap/screens의 후속 상태다. 새 디자인 실제 브라우저·320px/200% 확대/키보드/팝업 화면은 NOT_RUN, 공식 자동 브라우저 경로 장애 이력은 BLOCKED다.
