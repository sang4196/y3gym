본문 이미지 바꾸기 — 새 이미지를 먼저 넣고 기존 이미지 배치를 제거합니다.

  1. 본문의 텍스트 끝에 커서를 놓고 도구 모음의 이미지 버튼을 누릅니다. 이미 올린 파일은 목록에서 선택하고, 새 파일만 Upload로 올립니다.
  2. 이미지 설명·표시 형식을 확인하고 Insert image를 누릅니다. 새 이미지가 들어온 것을 확인한 뒤 기존 이미지를 클릭해 Delete로 그 배치만 제거합니다.
이미지 Edit, 좁은 편집 화면, 초안 저장 안내

기존 이미지의 Edit는 표시 형식·대체 설명 수정입니다. 다른 이미지 파일로 바꾸는 버튼이 아닙니다. 본문 이미지의 Delete는 본문 배치 제거이며 이미지 파일의 영구 삭제가 아닙니다.

편집 공간이 좁으면 상단 휴대폰 모양 Preview 버튼으로 미리보기 패널을 닫고 편집한 뒤 다시 열 수 있습니다. 입력이 반응하지 않으면 새로고침하지 말고 현재 화면과 증상을 알려 주세요.

현재 시험에서는 하단 Save draft로 저장합니다. Publish·Unpublish는 사용하지 않습니다. 같은 파일을 새 시험 자산으로 업로드해 중복 안내가 나오면 Use new image를 선택합니다.
